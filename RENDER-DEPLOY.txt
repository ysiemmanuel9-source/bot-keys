COMO PONER EL BOT DE KEYS EN RENDER

Este bot se crea en Render como Web Service para poder usar el plan Free.
El bot tambien abre una pagina simple de estado para que Render lo pueda mantener corriendo.

REPO

https://github.com/ysiemmanuel9-source/bot-keys

CONFIGURACION EN RENDER

Tipo: Web Service
Build Command: npm install
Start Command: npm start
Plan: Free

IMPORTANTE

Render Free puede dormir si no recibe visitas. Para que este siempre activo de verdad,
lo mas estable es plan pago. Si quieres usar Free, pon un monitor externo que visite
la URL del servicio cada pocos minutos.

VARIABLES QUE TIENES QUE PEGAR EN RENDER

Copia los valores desde tu archivo .env local y pegalos en Render > Environment.
No subas el archivo .env a GitHub.

DISCORD_TOKEN
GUILD_ID
KEYS_ADMIN_ROLE
KEYS_CATEGORY_NAME

GLLYZI_ADMIN_EMAIL
GLLYZI_ADMIN_PASSWORD

TRYHARD_ADMIN_EMAIL
TRYHARD_ADMIN_PASSWORD

BLACKOUT_ADMIN_EMAIL
BLACKOUT_ADMIN_PASSWORD

ZEUS_ADMIN_EMAIL
ZEUS_ADMIN_PASSWORD

DESPUES DE PEGAR VARIABLES

1. Save Changes
2. Manual Deploy
3. Clear build cache & deploy, si Render lo permite
4. Espera que diga Live

SI SALE ERROR

Abre Logs en Render.
Los errores mas comunes son:
- Falta DISCORD_TOKEN
- Falta una clave de Supabase
- Token del bot incorrecto
- El bot ya esta corriendo en otra parte con el mismo token
